# HTML Demo Page

A minimal browser-based demo that shows the quay hot-reload client in action.
Instead of performing an actual page reload, it intercepts messages and displays
them in an on-screen event log so you can observe the protocol in real time.

## Features

- Live connection status indicator (connected / connecting / disconnected)
- Counters for reload and CSS injection events
- Scrollable event log with colour-coded entries
- CSS hot-injection applied live — edit `styles.css` and watch it update
- Reload messages intercepted for demo purposes (not actually reloading)

## Quick Start

1. **Start quay** watching this directory:

   ```bash
   quay --path examples/html --port 3012
   ```

2. **Serve the HTML** with any static file server. For example:

   ```bash
   # Python
   python -m http.server 8000 --directory examples/html

   # Node.js (npx)
   npx serve examples/html

   # PHP
   php -S localhost:8000 -t examples/html
   ```

3. **Open** `http://localhost:8000` in your browser.

4. **Edit `styles.css`** (or any watched file) and observe the event log update
   in real time. CSS changes are hot-injected without a page reload.

## Customising the Port

If your quay server runs on a non-default port, update the `DEFAULT_PORT`
variable inside the `<script>` block in `index.html`, or add a `data-port`
attribute if you switch to the external script approach:

```html
<script src="/quay-client.js" data-port="4000"></script>
```

## Production Use

In production, replace the demo script in `index.html` with the standard
hot-reload client (which performs actual reloads):

```html
<script src="/quay-client.js"></script>
```

Or use the inline snippet generated by `quay --print-snippet`.
